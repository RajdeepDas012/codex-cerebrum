### Interview Questions
**Q:** How do you achieve thread-safe bit-setting in a shared array without using heavy mutual exclusion locks?  
**A:** By packing bits into words and using atomic word-level Compare-And-Swap (CAS) loops to apply bitwise OR masks.  

**Q:** Why can standard Bloom filters not support item deletions natively?  
**A:** Because clearing a bit hash position may inadvertently unset a bit shared by another validly inserted element, introducing false negatives.

### Interview Questions
**Q:** How do hazard pointers prevent race conditions during concurrent node deletion in a lock-free Skip Graph?  
**A:** Hazard pointers allow threads to register nodes they are currently accessing globally so that retiring threads defer actual memory deallocation until no active hazard pointers reference those nodes.  

**Q:** Why is a membership-vector-CAS primitive necessary when modifying skip graph node connections?  
**A:** It ensures that concurrent modifications to a node's level memberships and routing keys are committed atomically, preventing split-brain or inconsistent neighbor states across execution threads.
