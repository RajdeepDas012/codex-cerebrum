### Interview Questions
**Q:** How do you achieve thread-safe bit-setting in a shared array without using heavy mutual exclusion locks?

**Q:** Why can standard Bloom filters not support item deletions natively?

### Summary
A lock-free bounded SPSC ring buffer utilizes atomic sequence-number tracking and cache-line padding to safely and efficiently pass data between a single producer thread and a single consumer thread without locks. ### Key Points
- Utilizes atomic sequence-number tracking to synchronize write and read positions without traditional mutex locks.
- Employs cache-line padding to prevent false sharing between the producer's write pointer and the consumer's read pointer on multi-core processors.
- Bounded size ensures pre-allocated memory blocks, eliminating runtime allocations and reducing garbage collection pressure.
- Integrates hazard pointer memory reclamation patterns to guarantee safe memory access and deterministic lifetime management.

### Interview Questions
**Q:** Why is cache-line padding critical in an SPSC ring buffer design?  
**A:** It prevents false sharing by ensuring the producer's write pointer and consumer's read pointer reside on separate CPU cache lines, avoiding unnecessary cache invalidation traffic across cores.  

**Q:** How does an SPSC ring buffer avoid using mutexes while remaining thread-safe?  
**A:** It relies on atomic operations and memory ordering fences (acquire-release semantics) to coordinate head and tail pointers across the single producer and single consumer threads.
