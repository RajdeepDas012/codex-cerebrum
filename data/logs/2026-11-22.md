### Best Practices
- ✅ Always protect shared node references with hazard pointers prior to reading or traversing child pointers.
- ✅ Batch hash propagation updates where possible to minimize CAS contention across sibling nodes.

### Interview Questions
**Q:** How do hazard pointers prevent memory reclamation issues in a lock-free Merkle Tree?  
**A:** Hazard pointers allow threads to atomically declare which nodes they are currently accessing, preventing other threads from freeing those nodes until no hazard pointers reference them.  

**Q:** What is the primary challenge when propagating hash updates up a lock-free tree using CAS?  
**A:** Contention at parent nodes and handling intermediate states where child updates might be partially applied while other threads are reading the tree.
