void* acquire_hazard_pointer(std::atomic<void*>& node_ptr, HazardPointerRecord* rec) {
    void* ptr;
    do {
        ptr = node_ptr.load(std::memory_order_acquire);
        rec->hazard.store(ptr, std::memory_order_release);

    return ptr;
}

### Interview Questions
**Q:** How do hazard pointers prevent use-after-free errors in a lock-free suffix array structure?  
**A:** Hazard pointers allow threads to publish a reference they are currently accessing so that other threads defer freeing those nodes until no hazard pointer references them.  

**Q:** Why are standard mutexes inefficient for concurrent suffix array construction on multi-core systems?  
**A:** Mutexes introduce thread contention, context-switching overhead, and pipeline stalls, whereas lock-free atomic CAS primitives allow continuous forward progress.
