### Summary
The Turtle Trading System is a famous, fully mechanical trend-following breakout strategy developed by Richard Dennis and William Eckhardt. It utilizes Donchian channels for entry and exit signals, combined with a revolutionary volatility-based position sizing metric called ATR (Average True Range) known as 'Unit' sizing.

### Key Points
- System 1 uses a 20-day breakout for entry and a 10-day breakout in the opposite direction for exit.
- System 2 uses a longer-term 55-day breakout for entry and a 20-day breakout in the opposite direction for exit.
- Position sizing is determined by the Average True Range (ATR), where one 'Unit' equals 1% of total account equity divided by the dollar ATR.
- Pyramiding adds new units to winning positions as price moves favorably in increments of 0.5 ATR up to a maximum unit cap.

### Code Example
*Calculates Turtle system entry signals and ATR-based position sizing*

```python
import numpy as np

def turtle_signal(prices, highs_20, lows_10):
    long_entry = prices[-1] > np.max(highs_20[-20:])
    short_exit = prices[-1] < np.min(lows_10[-10:])
    return long_entry, short_exit
```
