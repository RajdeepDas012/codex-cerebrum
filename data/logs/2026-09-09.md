### Summary
Mean reversion trading with Bollinger Bands exploits the statistical tendency of prices to return to their moving average after reaching extreme volatility boundaries. It provides a mathematical edge in sideways or ranging markets by identifying overbought and oversold conditions relative to recent price action.

### Key Points
- Bollinger Bands consist of a middle simple moving average (usually 20-period) flanked by upper and lower bands set a specified number of standard deviations (typically 2) away.
- Prices touching or piercing the outer bands indicate statistical extremes, signaling potential reversal points back toward the mean.
- Band width contraction (the 'squeeze') often precedes significant breakouts, which signals a warning to pause mean-reversion strategies.
- Success relies heavily on filtering for sideways or non-trending market regimes using indicators like the Average Directional Index (ADX).

### Code Example
*Calculates Bollinger Bands and generates mean reversion entry signals.*

```python
import pandas as pd

def bollinger_mean_reversion(df, window=20, num_std=2):
    df['sma'] = df['close'].rolling(window=window).mean()
    df['std'] = df['close'].rolling(window=window).std()
    df['upper'] = df['sma'] + (df['std'] * num_std)
    df['lower'] = df['sma'] - (df['std'] * num_std)
    df['signal'] = 0
    df.loc[df['close'] < df['lower'], 'signal'] = 1  # Buy oversold
    df.loc[df['close'] > df['upper'], 'signal'] = -1 # Sell overbought
    return df
```

### Key Points
- VWAP calculates the average price traded throughout the session, weighted by volume at each price level.
- Standard deviation bands (e.g., ±1, ±2 standard deviations) are plotted around VWAP to measure overextended price moves.
- Trades are triggered when the price stretches to the outer deviation bands and then pulls back or reverses toward the central VWAP line.

### Code Example
*Calculates intraday VWAP and standard deviation bands using pandas*

```python
import numpy as np
import pandas as pd

def calculate_vwap_bands(df, num_std=2):
    typical_price = (df['high'] + df['low'] + df['close']) / 3
    cumulative_tp_vol = (typical_price * df['volume']).cumsum()
    cumulative_vol = df['volume'].cumsum()
    vwap = cumulative_tp_vol / cumulative_vol
    
    variance = (df['volume'] * (typical_price - vwap) ** 2).cumsum() / cumulative_vol
    stdev = np.sqrt(variance)
    
    df['vwap'] = vwap
    df['upper_band'] = vwap + (num_std * stdev)
    df['lower_band'] = vwap - (num_std * stdev)
    return df
```

### Summary
An inside day occurs when a trading session's entire high-to-low range is completely contained within the previous day's range, signaling a period of volatility compression and market indecision. The inside day breakout strategy captures explosive directional moves that typically follow this coiling behavior once price breaches either the mother bar's high or low.

### Key Points
- The 'mother bar' is the initial day with the larger range, and the 'inside day' represents the contraction phase.
- Breakouts can occur on the very next bar (day 3) or after multiple consecutive inside days, which further increases potential energy.
- Volume typically contracts during the inside day and expands sharply upon the breakout confirmation.
- Traders often place entry stop orders just beyond the high or low of the mother bar to catch impulsive momentum.

### Code Example
*Identifying inside days and generating breakout signals using pandas*
