*Demonstrates a thread-safe atomic update loop for a concurrent Fenwick Tree node using CAS operations.*

```cpp
void update(std::atomic<int>* tree, int n, int idx, int val) {
    while (idx <= n) {
        int current = tree[idx].load(std::memory_order_relaxed);
        while (!tree[idx].compare_exchange_weak(current, current + val, std::memory_order_release, std::memory_order_relaxed));
        idx += idx & -idx;
    }
}
```
