### Interview Questions
**Q:** How do hazard pointers prevent race conditions during memory reclamation in a lock-free suffix array?  
**A:** Hazard pointers allow a thread to announce which shared node it is currently accessing before reading, preventing other threads from reclaiming that memory until the reference is cleared.  

**Q:** Why are prefix-doubling algorithms challenging to implement in a lock-free concurrent environment?  
**A:** They require multiple threads to coordinate rank updates across exponentially increasing substring lengths atomically, making ABA problems and CAS retries frequent.
