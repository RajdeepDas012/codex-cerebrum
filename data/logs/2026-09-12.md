### Summary
A margin call cascade occurs when declining asset prices trigger widespread collateral deficits, forcing brokers to liquidate client positions regardless of fundamental value. This creates a self-reinforcing downward price spiral that can rapidly deplete market liquidity and trigger systemic financial stress.

### Key Points
- Brokers issue margin calls when an investor's equity falls below the maintenance margin requirement due to price drops.
- If the investor fails to deposit additional cash or securities, the broker automatically liquidates assets at market prices.
- Forced liquidations increase selling pressure, driving prices lower and triggering subsequent margin calls for other leveraged accounts.
- The feedback loop spreads across asset classes as institutions deleverage to meet liquidity demands, seizing up credit markets.

### Code Example
*Simulates a multi-step margin call cascade across leveraged portfolios*

```python
def simulate_cascade(prices, leverage, threshold):
    portfolio_value = prices * leverage
    equity = portfolio_value - (prices * (leverage - 1))
    margin_ratio = equity / portfolio_value
    forced_sells = margin_ratio < threshold
    return forced_sells
```

- ✅ Diversify funding sources and maintain a cash buffer to prevent forced liquidation of core long-term holdings.

### Code Example
*Detecting anomalies where volume spikes drastically while prices drop without sector-wide fundamental news*

```python
import pandas as pd

def identify_forced_selling(df, volume_z_threshold=3.0, return_threshold=-0.05):
    df['volume_mean'] = df['volume'].rolling(window=20).mean()
    df['volume_std'] = df['volume'].rolling(window=20).std()
```

### Code Example
*Identifies a potential buying climax using price range expansion and relative volume spikes.*

```python
import pandas as pd

def detect_buying_climax(df, volume_window=20, price_mult=2.0):
    avg_vol = df['volume'].rolling(volume_window).mean()
    price_range = df['high'] - df['low']
    avg_range = price_range.rolling(volume_window).mean()
    
    climax = (
        (df['volume'] > (avg_vol * 2.5)) &

    return climax
```

### Summary
Volume Accumulation/Distribution (A/D) is a momentum indicator that uses volume and price to assess whether a stock is being actively accumulated (bought) or distributed (sold) by institutional investors. It helps traders identify underlying supply and demand dynamics that may precede major price breakouts or breakdowns.

### Key Points
- Measures cumulative flow of volume relative to where the closing price sits within the daily high-low range.
- Rising A/D line during a flat or declining price trend suggests stealth accumulation by institutional smart money.
- Falling A/D line while prices are still rising warns of covert distribution and potential trend reversal.
- Differs from On-Balance Volume (OBV) because A/D weights volume by the exact location of the close rather than just positive/negative close direction.

### Code Example
*Calculate the Accumulation/Distribution Line using pandas*

```python
import pandas as pd

def calc_ad(df):
    clv = ((df['Close'] - df['Low']) - (df['High'] - df['Close'])) / (df['High'] - df['Low'])
    clv = clv.fillna(0)
    return (clv * df['Volume']).cumsum()
```

### Best Practices

### Interview Questions
**Q:** How does the Accumulation/Distribution indicator differ from On-Balance Volume (OBV)?

### Key Points
- Phase A halts the prior downtrend through the Preliminary Support (PS) and Selling Climax (SC), followed by an Automatic Rally (AR) and Secondary Test (ST).
- Phase B builds the cause by testing the trading range boundaries, where smart money absorbs floating supply and institutions quietly build large positions.
- Phase C features the Spring or Shakeout, a deliberate break below support to flush out weak retail holders and test market liquidity before the markup.
- Phase D witnesses the Last Point of Support (LPS) and signs of strength (SOS) as price moves consistently upward within the trading range toward the resistance line.
- Phase E marks the breakout and start of the markup phase, where price leaves the trading range permanently and enters a sustained bullish trend.

### Code Example
*Programmatically detecting potential Wyckoff Phase C springs using price extremes and volume confirmation.*

```python
def identify_wyckoff_spring(df, range_low, volume_ma_period):
```

### Key Points

- Phase D initiates the Sign of Weakness (SOW) and Last Point of Supply (LPSY), confirming that supply firmly controls the market as prices break support.
- Phase E marks the beginning of the actual markdown phase, characterized by persistent downward momentum and widening spreads away from the distribution range.

### Code Example

```python
import pandas as pd

def detect_utad(df):
    # UTAD: price breaks above the previous distribution range high on declining or high volume
    range_high = df['high'].iloc[-50:-10].max()
    utad_condition = (df['high'] > range_high) & (df['close'] < range_high)
```

```python
def is_reaccumulation(prices, volumes, markup_threshold):
    is_uptrend = prices[-1] > prices[0] * markup_threshold
    sideways_movement = (max(prices[-20:]) - min(prices[-20:])) / prices[-20] < 0.08

    return is_uptrend and sideways_movement and declining_volume
```
