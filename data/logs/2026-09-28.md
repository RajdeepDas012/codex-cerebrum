### Interview Questions
**Q:** How does a Treap maintain balance without explicit global rebalancing operations like those in AVL or Red-Black trees?  
**A:** A Treap assigns a randomly generated priority to each inserted node and maintains a max-heap property based on these priorities, which probabilistically keeps the tree well-balanced with expected logarithmic height.  

**Q:** Why are hazard pointers necessary when implementing a lock-free concurrent Treap?  
**A:** Hazard pointers protect threads from accessing memory that has been concurrently freed by another thread during structural modifications like rotations and deletions, preventing dangling pointer dereferences and memory corruption.
