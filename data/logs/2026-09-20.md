bool expand_bbox(Node* node, const BoundingBox& new_box) {
    BoundingBox current = node->bbox.load();
    BoundingBox updated;
    do {
        updated = current.merge(new_box);
        if (updated == current) return true;
    } while (!node->bbox.compare_exchange_weak(current, updated));

}

bool insert_child(std::atomic<Node*>& parent_link, Node* new_node) {

### Interview Questions
**Q:** How do you handle safe memory reclamation when multiple threads concurrently delete or split nodes in a lock-free suffix tree?  
**A:** By using hazard pointers to register nodes currently being accessed by a thread, deferring actual memory deallocation until no active thread holds a hazard reference to them.  

**Q:** Why is standard lock-based synchronization inefficient for concurrent suffix tree construction?  
**A:** Coarse-grained locking serializes tree modification, while fine-grained locking causes massive overhead and deadlock risks due to complex multi-node tree manipulations like suffix-link adjustments.
