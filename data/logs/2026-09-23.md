bool expand_bbox(std::atomic<BoundingBox*>& current_box, BoundingBox* new_inclusion) {
    BoundingBox* old_box = current_box.load();
    BoundingBox* expanded = new BoundingBox(*old_box);
    expanded->merge(*new_inclusion);
    while (!current_box.compare_exchange_weak(old_box, expanded)) {
        expanded->copy_from(*old_box);
        expanded->merge(*new_inclusion);
    }
    return true;
}

### Interview Questions
**Q:** How do you handle node splits in a lock-free R-Tree without acquiring a global tree lock?  
**A:** By using atomic CAS loops to replace an overflowing node with two newly allocated sibling nodes, utilizing hazard pointers to ensure safe retirement of the old node structure.  

**Q:** What is the primary purpose of hazard pointers in a concurrent spatial index like an R-Tree?  
**A:** To safely track references to nodes currently being accessed by reader threads so that writer threads know when it is safe to reclaim memory after structural modifications.
