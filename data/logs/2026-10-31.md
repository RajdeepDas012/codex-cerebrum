```cpp
        idx += idx & -idx;
    }
}
```

```cpp
void update(int idx, long long delta) {
    while (idx <= max_val) {
        tree[idx] += delta;
        idx += idx & -idx;
    }
}
```

### Best Practices
- ✅ Always use acquire-release memory ordering semantics with CAS loops to ensure visibility of updates across threads.
- ✅ Protect dynamic node allocations and deletions using hazard pointers or epoch-based memory reclamation.
