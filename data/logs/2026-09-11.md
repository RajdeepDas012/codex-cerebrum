### Summary

### Key Points
- Maximizes variance projection by finding orthogonal axes (principal components) that capture the highest spread in the data.
- Eigenvalue decomposition of the feature covariance matrix (or Singular Value Decomposition of the standardized data matrix) forms the mathematical backbone of PCA.
- Reduces the curse of dimensionality, helping machine learning models generalize better by removing noisy, redundant dimensions.
- Generates synthetic factor portfolios whose exposures can be used directly in multi-factor asset pricing models.

### Code Example
*Implementing a rolling walk-forward split for parameter tuning*

```python
import numpy as np

def walk_forward_split(data, train_size, test_size):
    n = len(data)
    for i in range(0, n - train_size - test_size + 1, test_size):
        train = data[i:i+train_size]
        test = data[i+train_size:i+train_size+test_size]
        yield train, test
```

### Summary

### Code Example
*Calculates risk parity weights using scipy optimization to equalize risk contributions*

```python
import numpy as np
from scipy.optimize import minimize

def risk_parity_weights(cov_matrix):
    n = cov_matrix.shape[0]
    initial_weights = np.ones(n) / n
    bounds = [(0.0, 1.0) for _ in range(n)]
    constraints = ({'type': 'eq', 'fun': lambda w: np.sum(w) - 1.0})
    
    def risk_budget_objective(weights):
        portfolio_variance = weights.T @ cov_matrix @ weights
        portfolio_vol = np.sqrt(portfolio_variance)
        marginal_risk = cov_matrix @ weights
        risk_contributions = weights * marginal_risk / portfolio_vol
        target_risk = portfolio_vol / n
        return np.sum((risk_contributions - target_risk)**2)
        
    result = minimize(risk_budget_objective, initial_weights, method='SLSQP', bounds=bounds, constraints=constraints)
    return result.x
```

### Summary
The minimum variance portfolio is a mathematical framework that allocates weights to a set of assets to achieve the lowest possible total portfolio volatility, regardless of expected returns. - Relies heavily on the covariance matrix of asset returns, making estimation error a critical factor.

### Code Example
*Constructing a minimum variance portfolio using scipy optimization*

```python
import numpy as np
from scipy.optimize import minimize

def get_min_var_weights(cov_matrix):
    num_assets = cov_matrix.shape[0]
    args = (cov_matrix,)
    def portfolio_variance(weights, cov_matrix):
        return np.dot(weights.T, np.dot(cov_matrix, weights))
    
    constraints = ({'type': 'eq', 'fun': lambda x: np.sum(x) - 1})
    bounds = tuple((0, 1) for _ in range(num_assets))
```

**Topic:** Consecutive loss analysis — drawdown depth and recovery time  
**Category:** `trading-strategies`  
**Difficulty:** `advanced`  
**Language:** `language-agnostic`  

### Summary
Consecutive loss analysis evaluates the distribution and clustering of losing trades to measure maximum drawdown depth and the duration required to recover to peak equity. It matters because understanding worst-case losing streaks prevents premature strategy abandonment and catastrophic margin calls.

### Key Points
- Drawdown depth measures the peak-to-trough percentage drop in account equity during a losing streak.
- Recovery time tracks the number of trades or days needed to claw back from the equity trough to the previous high.
- Probability theory dictates that even a high win-rate system will experience statistically predictable clusters of consecutive losses.
- Geometric growth compounds losses non-linearly, meaning a 50% drawdown requires a 100% gain just to break even.

### Code Example
*Calculates maximum consecutive losses and peak-to-trough drawdown depth from a trade return series.*

```python
def analyze_drawdowns(returns):
    import numpy as np
    equity = np.cumprod(1 + np.array(returns))
    peak = np.maximum.accumulate(equity)
    drawdown = (equity - peak) / peak
    max_dd = np.min(drawdown)
    
    # Max consecutive losses
    streak = 0
    max_streak = 0
    for r in returns:
        if r < 0:
            streak += 1
            max_streak = max(max_streak, streak)
        else:
            streak = 0
    return max_dd, max_streak
```

**❌ Common mistake:**
```python

    # WRONG: Assuming average loss size represents consecutive loss impact without compounding
    return sum(r for r in returns if r < 0)
```

### Best Practices
- ✅ Stress-test trading systems with Monte Carlo simulations to uncover hidden probabilities of extreme consecutive loss streaks.
- ✅ Size positions based on surviving at least double the maximum historical consecutive loss streak observed in backtesting.
- ✅ Implement circuit breakers that halt automated trading after a predefined depth of drawdown or consecutive loss count.

### Interview Questions
**Q:** If a trading system has a 60% win rate, what is the mathematical probability of experiencing 5 consecutive losses?

### Code Example
*Simulates a mean-reverting Vasicek process for the bid-ask spread to capture dynamic liquidity fluctuations.*

```python
import numpy as np

def simulate_spread(s0, kappa, theta, sigma, T, n):
    dt = T / n
    t = np.linspace(0, T, n)
    spread = np.zeros(n)
    spread[0] = s0
    for i in range(1, n):
        dw = np.random.normal(0, np.sqrt(dt))
        spread[i] = spread[i-1] + kappa * (theta - spread[i-1]) * dt + sigma * dw
        spread[i] = max(spread[i], 0.0001) # Ensure spread stays positive
    return t, spread
```

### Code Example
*Simulates a smart order router selecting the optimal venue based on net cost including exchange fees and rebates.*

```python
def route_order(venues, size, is_buy):
    best_venue = None
    best_price = float('inf') if is_buy else float('-inf')
    for venue, data in venues.items():
        if data['liquidity'] >= size:
            effective_price = data['ask'] if is_buy else data['bid']
            if is_buy and effective_price < best_price:
                best_price = effective_price
                best_venue = venue
            elif not is_buy and effective_price > best_price:
                best_price = effective_price
                best_venue = venue
    return best_venue
```
