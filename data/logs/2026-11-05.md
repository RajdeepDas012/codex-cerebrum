### Interview Questions
**Q:** How do you handle concurrent bit updates in a shared vector without using coarse-grained locks?  
**A:** By using atomic bitwise OR operations or Compare-And-Swap (CAS) loops targeting individual machine words or bytes.  

**Q:** Why might false positives increase in a concurrent environment if insertions are not synchronized properly?  
**A:** Race conditions on bit-vector updates can cause multiple threads to overwrite or corrupt bit flags if updates are missed or interleaved.
