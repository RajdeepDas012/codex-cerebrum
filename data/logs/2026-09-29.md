**Q:** How do hazard pointers prevent the ABA problem and memory reclamation races in a lock-free suffix array?  
**A:** Hazard pointers allow threads to locally register pointers they are currently accessing. Before a thread can free or reuse memory associated with a suffix node, it scans all active hazard pointers to ensure no other thread is referencing that memory block.
