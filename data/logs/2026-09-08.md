### Key Points

- Calculated using Weighted Moving Averages (WMAs) over half-period and full-period inputs.

*Calculates the Hull Moving Average using pandas and numpy*

```python
import numpy as np
import pandas as pd

def hull_moving_average(series, period):
    half_period = int(period / 2)
    sqrt_period = int(np.sqrt(period))
    wma_half = series.rolling(half_period).apply(lambda x: np.dot(x, np.arange(1, half_period + 1)) / np.sum(np.arange(1, half_period + 1)), raw=True)
    wma_full = series.rolling(period).apply(lambda x: np.dot(x, np.arange(1, period + 1)) / np.sum(np.arange(1, period + 1)), raw=True)
    diff = 2 * wma_half - wma_full
    hma = diff.rolling(sqrt_period).apply(lambda x: np.dot(x, np.arange(1, sqrt_period + 1)) / np.sum(np.arange(1, sqrt_period + 1)), raw=True)
```

### Summary
The Kaufman Adaptive Moving Average (KAMA) is a trend-following indicator designed to account for market noise and volatility. It automatically adjusts its smoothing constant, moving slower during choppy, sideways markets and faster during strong, directional trends.

### Key Points
- Incorporates an Efficiency Ratio (ER) that measures the net price movement relative to the total volatility of price paths.
- Uses a Scaling Factor derived from the Efficiency Ratio to dynamically adjust between fast and slow exponential moving average constants.
- Reduces whipsaws and false breakout signals significantly during periods of high market consolidation or noise.
- Reacts quickly to sharp price movements when a genuine trend establishes itself after a consolidation phase.

### Code Example
*Calculates the Kaufman Adaptive Moving Average using pandas*

```python
import pandas as pd
import numpy as np

def calculate_kama(series, n=10, fast=2, slow=30):
    change = series.diff(n).abs()
    volatility = series.diff(1).abs().rolling(window=n).sum()
    er = np.where(volatility == 0, 0, change / volatility)
    
    fast_sc = 2 / (fast + 1)
    slow_sc = 2 / (slow + 1)
    sc = (er * (fast_sc - slow_sc) + slow_sc) ** 2
    
    kama = np.zeros_like(series)
    kama[n-1] = series[n-1]
    for i in range(n, len(series)):
        kama[i] = kama[i-1] + sc[i] * (series[i] - kama[i-1])
    return pd.Series(kama, index=series.index)
```

**Q:** What is the purpose of the Efficiency Ratio (ER) in the calculation of KAMA?

### Key Points

- Automatically tightens proximity to price action when volatility expands aggressively.

### Code Example
*Calculating VIDYA using pandas and numpy based on the Chande Momentum Oscillator volatility index.*

```python
import numpy as np
import pandas as pd

def calculate_vidya(close_prices, period=9, alpha_fast=2/3, alpha_slow=2/30):
    delta = close_prices.diff()
    gain = delta.where(delta > 0, 0.0)
    loss = -delta.where(delta < 0, 0.0)
    
    sum_gain = gain.rolling(window=period).sum()
    sum_loss = loss.rolling(window=period).sum()
    
    # Chande Momentum Oscillator as volatility index
    cmo = np.abs((sum_gain - sum_loss) / (sum_gain + sum_loss))
    
    # Dynamic smoothing constant
    sc = (2.0 / (period + 1)) * cmo
    
    vidya = np.zeros_like(close_prices)
    vidya[0] = close_prices.iloc[0]
    
    for i in range(1, len(close_prices)):
        vidya[i] = sc.iloc[i] * close_prices.iloc[i] + (1 - sc.iloc[i]) * vidya[i-1]
        
    return pd.Series(vidya, index=close_prices.index)
```

```python
import pandas as pd

def calculate_mcginley(close, period=14, k=0.6):
```

### Code Example
*Demonstrates calculating the Least Squares Moving Average using numpy polyfit*

```python
import numpy as np

def lsma(prices, period):
    lsma_values = []
    for i in range(period - 1, len(prices)):
        y = prices[i - period + 1:i + 1]
```

- Significantly reduces phase delay (lag) compared to Simple (SMA) and Exponential (EMA) moving averages.

### Code Example
*Calculating the Arnaud Legoux Moving Average (ALMA) using numpy*

```python
import numpy as np

def calculate_alma(prices, window=9, offset=0.85, sigma=6.0):
    m = np.floor(offset * (window - 1))
    s = window / sigma
    weights = np.exp(-((np.arange(window) - m) ** 2) / (2 * s ** 2))
    weights /= weights.sum()
    return np.convolve(prices, weights[::-1], mode='valid')
```

### Code Example
*Calculating basic Renko brick generation logic using pandas*

```python
def generate_renko_bricks(prices, brick_size):
    bricks = [prices.iloc[0]]
    for price in prices[1:]:
        diff = price - bricks[-1]
        if abs(diff) >= brick_size:
            num_bricks = int(diff / brick_size)
            for i in range(1, abs(num_bricks) + 1):
                bricks.append(bricks[-1] + (brick_size * (1 if num_bricks > 0 else -1)))
    return bricks
```

### Summary
A linear regression channel is a statistical indicator that plots a best-fit trend line through price data along with parallel upper and lower boundary lines based on standard deviation. It matters because it provides an objective, math-based framework for identifying trend direction, mean reversion zones, and potential breakout levels without relying on subjective hand-drawn lines.

### Key Points
- The center line represents the linear regression line, calculating the least-squares best fit for a user-defined period.
- Outer parallel lines are typically set a fixed number of standard deviations (e.g., 2.0) away from the center line to capture normal price variance.
- Prices touching the lower boundary in an uptrend indicate potential oversold conditions or buying opportunities near structural support.
- A sustained break outside the outer boundary lines often signals an acceleration of the trend or a dramatic shift in market momentum.

### Code Example
*Calculate linear regression channel boundaries using pandas and numpy*

```python
import numpy as np
import pandas as pd

def calc_regression_channel(df, period=50):
    x = np.arange(period)
    y = df['close'].iloc[-period:].values
    slope, intercept = np.polyfit(x, y, 1)
    center = intercept + slope * x
    std_dev = np.std(y - center)
    upper = center + (2 * std_dev)
    lower = center - (2 * std_dev)
    return center[-1], upper[-1], lower[-1]
```

**❌ Common mistake:**
```python
center = df['close'].rolling(50).mean()
upper = center + df['close'].rolling(50).std() * 2
```

### Best Practices
- ✅ Combine regression channels with momentum oscillators like RSI to confirm exhaustion near the outer bands.
- ✅ Adjust the standard deviation multiplier based on the asset's historical volatility profile.

### Interview Questions
**Q:** How is the center line of a linear regression channel determined?  
**A:** It is calculated using the least-squares regression method to find the line of best fit through the price data over a specified lookback period.  

**Q:** What do the outer boundaries of a linear regression channel typically represent?  
**A:** They represent a set number of standard deviations away from the center regression line, capturing the statistical dispersion of prices around the trend.

### Summary
The Raff regression channel is a linear regression trend line flanked by upper and lower parallel boundaries set at a fixed multiple of standard deviations. It provides traders with an objective statistical framework to measure trend strength and identify overextended price moves.

### Key Points
- Constructed by calculating a least-squares linear regression line through a user-defined historical price series.
- Upper and lower channel boundaries are drawn parallel to the central regression line at a distance determined by the maximum high/low deviation (or standard deviation).
- Acts as a momentum and mean-reversion tool where touches of the outer boundaries signal potential exhaustion points.
- Dynamic in nature, as the anchor points shift, the entire channel recalculates its slope and boundaries.

### Code Example
*Calculates a basic linear regression channel with standard deviation boundaries using pandas and numpy.*

```python
import numpy as np
import pandas as pd

def calculate_raff_channel(prices, num_stds=2):
    x = np.arange(len(prices))
    slope, intercept = np.polyfit(x, prices, 1)
    regression_line = slope * x + intercept
    residuals = prices - regression_line
    std_dev = np.std(residuals)
    upper_channel = regression_line + (num_stds * std_dev)
    lower_channel = regression_line - (num_stds * std_dev)
    return regression_line, upper_channel, lower_channel
```

**❌ Common mistake:**
```python
def calculate_raff_channel(prices):
    # Mistake: using simple moving average instead of linear regression for the center line
    center = prices.rolling(window=20).mean()
    upper = center + (prices.rolling(window=20).std() * 2)
    return center, upper
```

### Best Practices
- ✅ Combine channel boundary rejections with momentum oscillators like the RSI to confirm overbought or oversold conditions.
- ✅ Use multiple timeframes to ensure the regression channel aligns with the broader macro market structure.

### Interview Questions
**Q:** How does a Raff regression channel differ from a standard moving average envelope?  
**A:** A Raff regression channel uses a least-squares central trend line derived from statistical regression, whereas moving average envelopes use lagged moving averages as their baseline.  

**Q:** What do consecutive closes outside the outer standard deviation boundary typically signify in a Raff channel?  
**A:** They often indicate a strong acceleration of momentum or a potential structural trend breakout rather than a routine mean-reversion opportunity.

```python
def calculate_fib_extensions(point_a, point_b, point_c):
```

### Summary
Parallel channel trading involves constructing upper and lower trendlines parallel to a dominant trend to systematically capture swing trading opportunities. It matters because it provides clear, bounded boundaries for establishing high-probability entry points at support/resistance and defined profit-taking exits at the opposite channel boundary.

### Key Points
- Channels are constructed by drawing a trendline connecting two major swing points and placing a parallel line across the intermediate counter-trend extreme.
- Ascending channels indicate a bullish trend where traders buy near the lower support line and take profit near the upper resistance line.
- Descending channels indicate a bearish trend where traders look to short near the upper resistance line and cover near the lower support line.
- The median line running parallel directly through the center of the channel often acts as a secondary pivot or midpoint target.

### Code Example
*Calculates parallel channel boundaries and generates long/short signals based on price proximity to channel lines.*

```python
import numpy as np
def channel_signals(highs, lows, closes, window=20):
    upper = np.maximum.accumulate(highs[-window:])
    lower = np.minimum.accumulate(lows[-window:])
    signals = np.where(closes <= lower * 1.002, 'BUY', np.where(closes >= upper * 0.998, 'SELL', 'HOLD'))
    return signals
```
