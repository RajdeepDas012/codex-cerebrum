**Category:** `technical-analysis`

### Summary
The Vortex Indicator is a technical analysis tool composed of two oscillating lines (VI+ and VI-) that measure positive and negative trend movements. It identifies trend reversals and confirms trend direction when one line crosses over the other.

### Key Points
- Consists of two lines: VI+ (upward trend movement) and VI- (downward trend movement).
- Calculated using the distance between current highs and lows relative to previous periods.
- A bullish reversal occurs when VI+ crosses above VI- from below.
- A bearish reversal occurs when VI- crosses above VI+ from below.

### Code Example
*Calculates the Vortex Indicator lines using pandas and numpy.*

```python
import pandas as pd
import numpy as np

def vortex_indicator(df, period=14):
    tr = pd.concat([df['High'] - df['Low'], abs(df['High'] - df['Close'].shift()), abs(df['Low'] - df['Close'].shift())], axis=1).max(axis=1)
    vmp = abs(df['High'] - df['Low'].shift())
    vmm = abs(df['Low'] - df['High'].shift())
    tr_sum = tr.rolling(period).sum()
    vi_plus = vmp.rolling(period).sum() / tr_sum
    vi_minus = vmm.rolling(period).sum() / tr_sum
    return vi_plus, vi_minus
```

**A:** A bullish trend reversal is signaled when the VI+ line crosses above the VI- line.  

**Q:** How does the Vortex indicator handle periods of high market consolidation?  
**A:** In consolidation, VI+ and VI- tend to intertwine closely, producing frequent false crossover signals requiring additional filtering.

### Summary
The Trix indicator is a momentum oscillator that displays the percentage rate of change of a triple exponentially smoothed moving average. By filtering out insignificant price noise through multiple smoothing steps, it helps traders spot major trend reversals while maintaining relatively low lag compared to traditional moving averages.

### Key Points
- Calculated by taking the percentage rate of change (ROC) of a triple exponential moving average (EMA).
- Triple smoothing effectively removes random market noise and insignificant price fluctuations.
- Often plotted alongside a signal line to generate zero-line crossovers and divergence signals.
- Acts as both a momentum indicator and a trend-following tool.

### Code Example
*Demonstrates calculating the Trix indicator using pandas and exponential moving averages*

```python
import pandas as pd
def calculate_trix(df, period=15):
    ema1 = df['Close'].ewm(span=period, adjust=False).mean()
    ema2 = ema1.ewm(span=period, adjust=False).mean()
    ema3 = ema2.ewm(span=period, adjust=False).mean()
    trix = ema3.pct_change() * 100
    return trix
```

## Run #254 — 04:00 UTC

**Topic:** Know sure thing KST — smoothed rate of change for trend confirmation  
**Category:** `technical-analysis`  
**Difficulty:** `intermediate`  
**Language:** `language-agnostic`  

### Summary
The Know Sure Thing (KST) is a momentum oscillator based on the smoothed rate-of-change (ROC) values across four different timeframes. It helps traders identify major trend reversals and confirm prevailing momentum by synthesizing short, intermediate, and long-term cycles.

### Key Points
- Calculated by summing four different smoothed Rate of Change (ROC) periods, each weighted by its timeframe importance.
- Includes a signal line (typically a 9-period SMA of the KST line) to generate crossover triggers.
- Oscillates around a zero line, where positive values indicate bullish momentum and negative values indicate bearish momentum.
- Particularly useful for spotting cyclical trend turns and divergence patterns against price action.

### Code Example
*Calculating the KST indicator using pandas and custom smoothing functions*

```python
import pandas as pd

def calculate_kst(df, close_col='close'):
    roc1 = df[close_col].pct_change(10) * 100
    roc2 = df[close_col].pct_change(15) * 100
    roc3 = df[close_col].pct_change(20) * 100
    roc4 = df[close_col].pct_change(30) * 100
    
    sma1 = roc1.rolling(10).mean()
    sma2 = roc2.rolling(10).mean()
    sma3 = roc3.rolling(15).mean()
    sma4 = roc4.rolling(30).mean()
    
    kst = (sma1 * 1) + (sma2 * 2) + (sma3 * 3) + (sma4 * 4)
    signal = kst.rolling(9).mean()
    return kst, signal
```

### Interview Questions
**Q:** How does the Know Sure Thing (KST) differ from a standard Rate of Change (ROC) indicator?  
**A:** While a standard ROC measures price change over a single timeframe, KST calculates and sums smoothed ROC values across four distinct timeframes, applying specific weights to each to provide a more holistic momentum signal.  

**Q:** What primary trading signals are generated by the KST indicator?  
**A:** Primary signals include KST line crossovers above or below the signal line, zero-line crossovers indicating overall bullish or bearish momentum shifts, and divergence patterns between KST and price action.
