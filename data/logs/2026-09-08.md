### Summary
The Vortex Indicator is a technical analysis tool composed of two oscillating lines (VI+ and VI-) that measure positive and negative trend movements. It identifies trend reversals and confirms trend direction when one line crosses over the other.

### Key Points
- Consists of two lines: VI+ (upward trend movement) and VI- (downward trend movement).
- Calculated using the distance between current highs and lows relative to previous periods.
- A bullish reversal occurs when VI+ crosses above VI- from below.
- A bearish reversal occurs when VI- crosses above VI+ from below.

### Code Example
*Calculates the Vortex Indicator lines using pandas and numpy.*

```python
import pandas as pd
import numpy as np

def vortex_indicator(df, period=14):
    tr = pd.concat([df['High'] - df['Low'], abs(df['High'] - df['Close'].shift()), abs(df['Low'] - df['Close'].shift())], axis=1).max(axis=1)
    vmp = abs(df['High'] - df['Low'].shift())
    vmm = abs(df['Low'] - df['High'].shift())
    tr_sum = tr.rolling(period).sum()
    vi_plus = vmp.rolling(period).sum() / tr_sum
    vi_minus = vmm.rolling(period).sum() / tr_sum
    return vi_plus, vi_minus
```

**A:** A bullish trend reversal is signaled when the VI+ line crosses above the VI- line.

**A:** In consolidation, VI+ and VI- tend to intertwine closely, producing frequent false crossover signals requiring additional filtering.

### Summary
The Trix indicator is a momentum oscillator that displays the percentage rate of change of a triple exponentially smoothed moving average. By filtering out insignificant price noise through multiple smoothing steps, it helps traders spot major trend reversals while maintaining relatively low lag compared to traditional moving averages.

### Key Points
- Calculated by taking the percentage rate of change (ROC) of a triple exponential moving average (EMA).
- Triple smoothing effectively removes random market noise and insignificant price fluctuations.
- Often plotted alongside a signal line to generate zero-line crossovers and divergence signals.
- Acts as both a momentum indicator and a trend-following tool.

### Code Example
*Demonstrates calculating the Trix indicator using pandas and exponential moving averages*

```python
import pandas as pd
def calculate_trix(df, period=15):
    ema1 = df['Close'].ewm(span=period, adjust=False).mean()
    ema2 = ema1.ewm(span=period, adjust=False).mean()
    ema3 = ema2.ewm(span=period, adjust=False).mean()
    trix = ema3.pct_change() * 100
    return trix
```
