### Summary
The Vortex Indicator is a technical analysis tool composed of two oscillating lines (VI+ and VI-) that measure positive and negative trend movements. It identifies trend reversals and confirms trend direction when one line crosses over the other.

### Key Points
- Consists of two lines: VI+ (upward trend movement) and VI- (downward trend movement).
- Calculated using the distance between current highs and lows relative to previous periods.
- A bullish reversal occurs when VI+ crosses above VI- from below.
- A bearish reversal occurs when VI- crosses above VI+ from below.

### Code Example
*Calculates the Vortex Indicator lines using pandas and numpy.*

```python
import pandas as pd
import numpy as np

def vortex_indicator(df, period=14):
    tr = pd.concat([df['High'] - df['Low'], abs(df['High'] - df['Close'].shift()), abs(df['Low'] - df['Close'].shift())], axis=1).max(axis=1)
    vmp = abs(df['High'] - df['Low'].shift())
    vmm = abs(df['Low'] - df['High'].shift())
    tr_sum = tr.rolling(period).sum()
    vi_plus = vmp.rolling(period).sum() / tr_sum
    vi_minus = vmm.rolling(period).sum() / tr_sum
    return vi_plus, vi_minus
```

- Oscillates around a zero line, where positive values indicate bullish momentum and negative values indicate bearish momentum.

### Code Example
*Calculating the KST indicator using pandas and custom smoothing functions*

```python
import pandas as pd

def calculate_kst(df, close_col='close'):
    roc1 = df[close_col].pct_change(10) * 100
    roc2 = df[close_col].pct_change(15) * 100
    roc3 = df[close_col].pct_change(20) * 100
    roc4 = df[close_col].pct_change(30) * 100
    
    sma1 = roc1.rolling(10).mean()
    sma2 = roc2.rolling(10).mean()
    sma3 = roc3.rolling(15).mean()
    sma4 = roc4.rolling(30).mean()
    
    kst = (sma1 * 1) + (sma2 * 2) + (sma3 * 3) + (sma4 * 4)
    signal = kst.rolling(9).mean()
    return kst, signal
```

### Key Points

- Applies a first stochastic calculation to the MACD values to capture cyclical turns.

### Code Example
*Demonstrates calculating the Schaff Trend Cycle using pandas and numpy*

```python
import pandas as pd
def schaff_trend_cycle(df, short_period=23, long_period=50, cycle_length=10):
    macd = df['Close'].ewm(span=short_period).mean() - df['Close'].ewm(span=long_period).mean()
    stoch1 = (macd - macd.rolling(cycle_length).min()) / (macd.rolling(cycle_length).max() - macd.rolling(cycle_length).min()) * 100
    stoch_smooth1 = stoch1.ewm(span=cycle_length // 2).mean()
    stoch2 = (stoch_smooth1 - stoch_smooth1.rolling(cycle_length).min()) / (stoch_smooth1.rolling(cycle_length).max() - stoch_smooth1.rolling(cycle_length).min()) * 100
```

### Summary
The Double Exponential Moving Average (DEMA) is designed to minimize the inherent lag of traditional moving averages by giving more weight to recent data. Developed by Patrick Mulloy, it calculates a weighted difference between a single EMA and a double EMA to hug price action much tighter.

### Key Points
- DEMA significantly reduces lag compared to a standard Simple Moving Average (SMA) or Exponential Moving Average (EMA).
- It is calculated using the formula: DEMA = (2 * EMA) - (EMA of EMA).
- Despite being called 'double', it does not simply apply an EMA twice, which would actually increase lag; rather, it uses the dual calculation to correct for the delay.
- It responds faster to sudden trend changes, making it popular for short-term and momentum trading strategies.

### Code Example
*Calculates the Double Exponential Moving Average using pandas*

```python
import pandas as pd

def calculate_dema(series, span):
    ema1 = series.ewm(span=span, adjust=False).mean()
    ema2 = ema1.ewm(span=span, adjust=False).mean()
    dema = (2 * ema1) - ema2
    return dema
```

**❌ Common mistake:**
```python

```

### Best Practices
- ✅ Combine DEMA with a volume or volatility indicator (like Average True Range) to filter out noise in choppy markets.
- ✅ Use two DEMAs of different periods (e.g., fast and slow) to generate crossover signals with much lower latency than standard EMA pairs.
- ✅ Test your strategy across different market regimes, as reduced lag can lead to overtrading in range-bound conditions.

### Interview Questions
**Q:** How does DEMA achieve reduced lag compared to a traditional EMA?  
**A:** DEMA subtracts a double-smoothed EMA from twice a single EMA, effectively scaling up the value to offset the delay inherent in exponential smoothing.  

**Q:** What is the primary trade-off when using a low-lag indicator like DEMA?  
**A:** The primary trade-off is an increase in susceptibility to false breakouts and whipsaws during ranging or choppy market conditions.

### Summary
The Triple Exponential Moving Average (TEMA) is a technical indicator designed to remove the lag inherent in traditional moving averages by using a combination of single, double, and triple exponential smoothing. It reacts much faster to price changes while maintaining enough smoothing to filter out erratic market noise.

### Key Points
- Calculated using the formula: (3 * EMA1) - (3 * EMA2) + EMA3, where EMA1 is a standard EMA, EMA2 is the EMA of EMA1, and EMA3 is the EMA of EMA2.
- Significantly reduces lag compared to standard Simple Moving Averages (SMA) and Exponential Moving Averages (EMA).
- Prone to whipsaws in sideways or range-bound markets due to its high sensitivity to price action.
- Invented by Patrick Mulloy in 1994 specifically to address the trade-off between smoothing and responsiveness.

### Code Example
*Calculates the Triple Exponential Moving Average using pandas*

```python
import pandas as pd

def calculate_tema(series, period):
    ema1 = series.ewm(span=period, adjust=False).mean()
    ema2 = ema1.ewm(span=period, adjust=False).mean()
    ema3 = ema2.ewm(span=period, adjust=False).mean()
    tema = (3 * ema1) - (3 * ema2) + ema3
    return tema
```

### Summary
The Hull Moving Average (HMA) developed by Alan Hull is a rapidly responsive moving average that significantly reduces lag while maintaining curve smoothness. It achieves this by using weighted moving averages (WMAs) across different periods and applying a square root time reduction technique.

### Key Points
- Significantly reduces the lag inherent in traditional moving averages like the SMA or EMA.
- Calculated using Weighted Moving Averages (WMAs) over half-period and full-period inputs.
- Applies a final WMA over the square root of the period to smooth out the resulting line.
- Provides quick trend reversals making it popular for momentum and swing trading strategies.

### Code Example
*Calculates the Hull Moving Average using pandas and numpy*

```python
import numpy as np
import pandas as pd

def hull_moving_average(series, period):
    half_period = int(period / 2)
    sqrt_period = int(np.sqrt(period))
    wma_half = series.rolling(half_period).apply(lambda x: np.dot(x, np.arange(1, half_period + 1)) / np.sum(np.arange(1, half_period + 1)), raw=True)
    wma_full = series.rolling(period).apply(lambda x: np.dot(x, np.arange(1, period + 1)) / np.sum(np.arange(1, period + 1)), raw=True)
    diff = 2 * wma_half - wma_full
    hma = diff.rolling(sqrt_period).apply(lambda x: np.dot(x, np.arange(1, sqrt_period + 1)) / np.sum(np.arange(1, sqrt_period + 1)), raw=True)
    return hma
```


### Best Practices
- ✅ Combine HMA with volatility indicators like Average True Range (ATR) to filter out false breakouts.
- ✅ Use shorter periods for aggressive intraday momentum strategies and longer periods for swing trading.
- ✅ Watch for the slope direction of the HMA line as a primary signal for trend continuation.

### Interview Questions
**Q:** How does the Hull Moving Average manage to reduce lag compared to a Simple Moving Average?  
**A:** It utilizes weighted moving averages over halved time periods and applies a square root calculation to eliminate the lag introduced by smoothing.  

**Q:** What is the primary trade-off when using the Hull Moving Average instead of a standard EMA?  
**A:** While HMA reduces lag significantly, its increased sensitivity can result in more whipsaws and false signals during choppy market conditions.

**Topic:** Kaufman adaptive moving average KAMA — adapts to market volatility  
**Category:** `technical-analysis`  
**Difficulty:** `advanced`  
**Language:** `language-agnostic`  

### Summary
The Kaufman Adaptive Moving Average (KAMA) is a trend-following indicator designed to account for market noise and volatility. It automatically adjusts its smoothing constant, moving slower during choppy, sideways markets and faster during strong, directional trends.

### Key Points
- Incorporates an Efficiency Ratio (ER) that measures the net price movement relative to the total volatility of price paths.
- Uses a Scaling Factor derived from the Efficiency Ratio to dynamically adjust between fast and slow exponential moving average constants.
- Reduces whipsaws and false breakout signals significantly during periods of high market consolidation or noise.
- Reacts quickly to sharp price movements when a genuine trend establishes itself after a consolidation phase.

### Code Example
*Calculates the Kaufman Adaptive Moving Average using pandas*

```python
import pandas as pd
import numpy as np

def calculate_kama(series, n=10, fast=2, slow=30):
    change = series.diff(n).abs()
    volatility = series.diff(1).abs().rolling(window=n).sum()
    er = np.where(volatility == 0, 0, change / volatility)
    
    fast_sc = 2 / (fast + 1)
    slow_sc = 2 / (slow + 1)
    sc = (er * (fast_sc - slow_sc) + slow_sc) ** 2
    
    kama = np.zeros_like(series)
    kama[n-1] = series[n-1]
    for i in range(n, len(series)):
        kama[i] = kama[i-1] + sc[i] * (series[i] - kama[i-1])
    return pd.Series(kama, index=series.index)
```


### Best Practices
- ✅ Backtest KAMA parameters against specific asset volatilities, as crypto markets require different tuning compared to forex or equities.
- ✅ Combine KAMA with momentum oscillators to confirm trend breakouts rather than relying solely on price crossovers.

### Interview Questions
**Q:** How does KAMA differ from traditional moving averages like SMA or EMA?  
**A:** Unlike SMA or EMA which use fixed time periods, KAMA incorporates an Efficiency Ratio to dynamically adjust its sensitivity based on market noise and volatility.  

**Q:** What is the purpose of the Efficiency Ratio (ER) in the calculation of KAMA?  
**A:** The ER measures the directional efficiency of price movement by dividing the net price change over a period by the sum of individual absolute price changes, effectively gauging market noise.
