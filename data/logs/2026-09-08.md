### Summary
The Vortex Indicator is a technical analysis tool composed of two oscillating lines (VI+ and VI-) that measure positive and negative trend movements. It identifies trend reversals and confirms trend direction when one line crosses over the other.

### Key Points
- Consists of two lines: VI+ (upward trend movement) and VI- (downward trend movement).
- Calculated using the distance between current highs and lows relative to previous periods.
- A bullish reversal occurs when VI+ crosses above VI- from below.
- A bearish reversal occurs when VI- crosses above VI+ from below.

### Code Example
*Calculates the Vortex Indicator lines using pandas and numpy.*

```python
import pandas as pd
import numpy as np

def vortex_indicator(df, period=14):
    tr = pd.concat([df['High'] - df['Low'], abs(df['High'] - df['Close'].shift()), abs(df['Low'] - df['Close'].shift())], axis=1).max(axis=1)
    vmp = abs(df['High'] - df['Low'].shift())
    vmm = abs(df['Low'] - df['High'].shift())
    tr_sum = tr.rolling(period).sum()
    vi_plus = vmp.rolling(period).sum() / tr_sum
    vi_minus = vmm.rolling(period).sum() / tr_sum
    return vi_plus, vi_minus
```
