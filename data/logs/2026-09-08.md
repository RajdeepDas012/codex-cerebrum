### Key Points

- Calculated using Weighted Moving Averages (WMAs) over half-period and full-period inputs.

*Calculates the Hull Moving Average using pandas and numpy*

```python
import numpy as np
import pandas as pd

def hull_moving_average(series, period):
    half_period = int(period / 2)
    sqrt_period = int(np.sqrt(period))
    wma_half = series.rolling(half_period).apply(lambda x: np.dot(x, np.arange(1, half_period + 1)) / np.sum(np.arange(1, half_period + 1)), raw=True)
    wma_full = series.rolling(period).apply(lambda x: np.dot(x, np.arange(1, period + 1)) / np.sum(np.arange(1, period + 1)), raw=True)
    diff = 2 * wma_half - wma_full
    hma = diff.rolling(sqrt_period).apply(lambda x: np.dot(x, np.arange(1, sqrt_period + 1)) / np.sum(np.arange(1, sqrt_period + 1)), raw=True)
```

### Summary
The Kaufman Adaptive Moving Average (KAMA) is a trend-following indicator designed to account for market noise and volatility. It automatically adjusts its smoothing constant, moving slower during choppy, sideways markets and faster during strong, directional trends.

### Key Points
- Incorporates an Efficiency Ratio (ER) that measures the net price movement relative to the total volatility of price paths.
- Uses a Scaling Factor derived from the Efficiency Ratio to dynamically adjust between fast and slow exponential moving average constants.
- Reduces whipsaws and false breakout signals significantly during periods of high market consolidation or noise.
- Reacts quickly to sharp price movements when a genuine trend establishes itself after a consolidation phase.

### Code Example
*Calculates the Kaufman Adaptive Moving Average using pandas*

```python
import pandas as pd
import numpy as np

def calculate_kama(series, n=10, fast=2, slow=30):
    change = series.diff(n).abs()
    volatility = series.diff(1).abs().rolling(window=n).sum()
    er = np.where(volatility == 0, 0, change / volatility)
    
    fast_sc = 2 / (fast + 1)
    slow_sc = 2 / (slow + 1)
    sc = (er * (fast_sc - slow_sc) + slow_sc) ** 2
    
    kama = np.zeros_like(series)
    kama[n-1] = series[n-1]
    for i in range(n, len(series)):
        kama[i] = kama[i-1] + sc[i] * (series[i] - kama[i-1])
    return pd.Series(kama, index=series.index)
```

**Q:** What is the purpose of the Efficiency Ratio (ER) in the calculation of KAMA?

### Key Points

- Automatically tightens proximity to price action when volatility expands aggressively.

### Code Example
*Calculating VIDYA using pandas and numpy based on the Chande Momentum Oscillator volatility index.*

```python
import numpy as np
import pandas as pd

def calculate_vidya(close_prices, period=9, alpha_fast=2/3, alpha_slow=2/30):
    delta = close_prices.diff()
    gain = delta.where(delta > 0, 0.0)
    loss = -delta.where(delta < 0, 0.0)
    
    sum_gain = gain.rolling(window=period).sum()
    sum_loss = loss.rolling(window=period).sum()
    
    # Chande Momentum Oscillator as volatility index
    cmo = np.abs((sum_gain - sum_loss) / (sum_gain + sum_loss))
    
    # Dynamic smoothing constant
    sc = (2.0 / (period + 1)) * cmo
    
    vidya = np.zeros_like(close_prices)
    vidya[0] = close_prices.iloc[0]
    
    for i in range(1, len(close_prices)):
        vidya[i] = sc.iloc[i] * close_prices.iloc[i] + (1 - sc.iloc[i]) * vidya[i-1]
        
    return pd.Series(vidya, index=close_prices.index)
```

```python
import pandas as pd

def calculate_mcginley(close, period=14, k=0.6):
```

### Code Example
*Demonstrates calculating the Least Squares Moving Average using numpy polyfit*

```python
import numpy as np

def lsma(prices, period):
    lsma_values = []
    for i in range(period - 1, len(prices)):
        y = prices[i - period + 1:i + 1]
```

- Significantly reduces phase delay (lag) compared to Simple (SMA) and Exponential (EMA) moving averages.

### Code Example
*Calculating the Arnaud Legoux Moving Average (ALMA) using numpy*

```python
import numpy as np

def calculate_alma(prices, window=9, offset=0.85, sigma=6.0):
    m = np.floor(offset * (window - 1))
    s = window / sigma
    weights = np.exp(-((np.arange(window) - m) ** 2) / (2 * s ** 2))
    weights /= weights.sum()
    return np.convolve(prices, weights[::-1], mode='valid')
```

### Code Example
*Calculating basic Renko brick generation logic using pandas*

```python
def generate_renko_bricks(prices, brick_size):
    bricks = [prices.iloc[0]]
    for price in prices[1:]:
        diff = price - bricks[-1]
        if abs(diff) >= brick_size:
            num_bricks = int(diff / brick_size)
            for i in range(1, abs(num_bricks) + 1):
                bricks.append(bricks[-1] + (brick_size * (1 if num_bricks > 0 else -1)))
    return bricks
```

```python
    is_downtrend = c1_close < c1_open
    gaps_down = c2_open < c1_close
    pierces_midpoint = c2_close > (c1_open + c1_close) / 2 and c2_close < c1_open
    return is_downtrend and gaps_down and pierces_midpoint
```

**❌ Common mistake:**

```python
def is_piercing_line(c1_open, c1_close, c2_open, c2_close):
    return c2_close > c1_open
```

### Best Practices
- ✅ Verify that the second candle gaps away from the prior close before reversing direction.
- ✅ Combine the pattern with secondary indicators like RSI or MACD to confirm overbought or oversold conditions.
- ✅ Set stop-losses just beyond the extreme high of the dark cloud cover or the extreme low of the piercing line.

### Interview Questions
**Q:** What is the primary structural difference between a piercing line pattern and a bullish engulfing pattern?  
**A:** While both are bullish reversal patterns, a piercing line requires a gap down on the second candle's open and a close past the 50% midpoint of the first candle, whereas a bullish engulfing pattern's second candle completely engulfs the entire real body of the first candle.

## Run #300 — 18:28 UTC

**Topic:** Tweezer tops and bottoms — equal highs and lows reversal signal  
**Category:** `technical-analysis`  
**Difficulty:** `beginner`  
**Language:** `language-agnostic`  

### Summary
Tweezer tops and bottoms are two-candle reversal patterns where consecutive candles share nearly identical highs (tops) or lows (bottoms). They indicate that a market has tested a specific price level twice and failed to break through, signaling potential exhaustion of the current trend.

### Key Points
- A tweezer top occurs in an uptrend when two consecutive candles reach the exact same maximum price.
- A tweezer bottom occurs in a downtrend when two consecutive candles drop to the exact same minimum price.
- The pattern derives its name from a pair of tweezers, as the candles look like twin tips matching at the extreme boundary.
- Reliability increases significantly when the pattern forms near major support or resistance levels, or coincides with technical indicators like RSI divergence.

### Code Example
*Detects basic tweezer top patterns based on identical high prices within a tolerance range.*

```python
def is_tweezer_top(candle1, candle2, tolerance=0.0001):
    return abs(candle1['high'] - candle2['high']) <= tolerance and candle1['close'] < candle1['open'] and candle2['close'] < candle2['open']
```

**❌ Common mistake:**
```python
def is_tweezer_top(candle1, candle2):
    return candle1['high'] == candle2['high']
```

### Best Practices
- ✅ Look for the pattern on higher timeframe charts like daily or 4-hour intervals for higher statistical reliability.
- ✅ Combine the tweezer signal with volume analysis, such as decreasing volume on the second candle test.
- ✅ Set stop-losses just above the tweezer top or just below the tweezer bottom to manage risk effectively.

### Interview Questions
**Q:** What market psychology does a tweezer top represent?  
**A:** It shows buyers pushed the price up to a specific resistance level where sellers stepped in forcefully twice, creating exhaustion and signaling a shift in control to the bears.  

**Q:** Why is tolerance important when programming a detection algorithm for tweezer patterns?  
**A:** Because financial markets rarely print identical prices down to the pip or tick twice due to liquidity fluctuations, requiring an acceptable threshold range.

## Run #301 — 18:32 UTC

**Topic:** Spinning top candlestick — indecision candle at key levels  
**Category:** `technical-analysis`  
**Difficulty:** `beginner`  
**Language:** `language-agnostic`  

### Summary
A spinning top is a single candlestick pattern featuring a small real body centered between long upper and lower shadows. It represents a state of indecision between buyers and sellers, signaling that the prior trend may be losing momentum, especially when formed near major support or resistance levels.

### Key Points
- Characterized by a small body (open and close are close together) and long upper and lower wicks of roughly equal length.
- Indicates a tug-of-war where neither bulls nor bears could gain permanent control during the trading session.
- Serves as a warning sign of potential trend exhaustion or reversal when appearing after a strong rally or sell-off.
- Carries higher predictive significance when identified near established technical barriers such as moving averages, swing highs, or lows.

### Code Example
*Demonstrates programmatic identification of a spinning top candlestick using Pandas.*

```python
import pandas as pd

def is_spinning_top(open_price, close_price, high, low):
    body = abs(close_price - open_price)
    total_range = high - low
    upper_shadow = high - max(open_price, close_price)
    lower_shadow = min(open_price, close_price) - low
    # Body is less than 30% of total range, and both wicks are significant
    return (body <= total_range * 0.3) and (upper_shadow > body) and (lower_shadow > body)
```

**❌ Common mistake:**
```python
def is_spinning_top(open_price, close_price, high, low):
    # Incorrectly assumes a spinning top must have zero body and equal wicks
    return open_price == close_price and (high - open_price) == (open_price - low)
```

### Best Practices
- ✅ Always look for confluence by pairing the spinning top signal with volume analysis or secondary indicators like RSI or MACD.
- ✅ Wait for the next candle to break the high or low of the spinning top before committing capital.
- ✅ Place stop-loss orders just beyond the extreme wick of the spinning top to manage risk tightly.

### Interview Questions
**Q:** What market psychology does a spinning top candlestick represent?  
**A:** It reflects market indecision and equilibrium, where aggressive buying and selling occurred during the session, but neither side managed to close the price significantly higher or lower than the open.  

**Q:** Why is context critical when analyzing a spinning top?  
**A:** Because a spinning top merely indicates indecision; its predictive value entirely depends on where it appears, such as continuing a range-bound market versus signaling a reversal at a key resistance level.
