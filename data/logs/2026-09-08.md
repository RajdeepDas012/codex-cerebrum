def vortex_indicator(df, period=14):

### Key Points

- Calculated using Weighted Moving Averages (WMAs) over half-period and full-period inputs.
- Applies a final WMA over the square root of the period to smooth out the resulting line.
- Provides quick trend reversals making it popular for momentum and swing trading strategies.

### Code Example
*Calculates the Hull Moving Average using pandas and numpy*

import numpy as np
import pandas as pd

def hull_moving_average(series, period):
    half_period = int(period / 2)
    sqrt_period = int(np.sqrt(period))
    wma_half = series.rolling(half_period).apply(lambda x: np.dot(x, np.arange(1, half_period + 1)) / np.sum(np.arange(1, half_period + 1)), raw=True)
    wma_full = series.rolling(period).apply(lambda x: np.dot(x, np.arange(1, period + 1)) / np.sum(np.arange(1, period + 1)), raw=True)
    diff = 2 * wma_half - wma_full
    hma = diff.rolling(sqrt_period).apply(lambda x: np.dot(x, np.arange(1, sqrt_period + 1)) / np.sum(np.arange(1, sqrt_period + 1)), raw=True)

### Summary
The Kaufman Adaptive Moving Average (KAMA) is a trend-following indicator designed to account for market noise and volatility. It automatically adjusts its smoothing constant, moving slower during choppy, sideways markets and faster during strong, directional trends.

### Key Points
- Incorporates an Efficiency Ratio (ER) that measures the net price movement relative to the total volatility of price paths.
- Uses a Scaling Factor derived from the Efficiency Ratio to dynamically adjust between fast and slow exponential moving average constants.
- Reduces whipsaws and false breakout signals significantly during periods of high market consolidation or noise.
- Reacts quickly to sharp price movements when a genuine trend establishes itself after a consolidation phase.

### Code Example
*Calculates the Kaufman Adaptive Moving Average using pandas*

```python
import pandas as pd
import numpy as np

def calculate_kama(series, n=10, fast=2, slow=30):
    change = series.diff(n).abs()
    volatility = series.diff(1).abs().rolling(window=n).sum()
    er = np.where(volatility == 0, 0, change / volatility)
    
    fast_sc = 2 / (fast + 1)
    slow_sc = 2 / (slow + 1)
    sc = (er * (fast_sc - slow_sc) + slow_sc) ** 2
    
    kama = np.zeros_like(series)
    kama[n-1] = series[n-1]
    for i in range(n, len(series)):
        kama[i] = kama[i-1] + sc[i] * (series[i] - kama[i-1])
    return pd.Series(kama, index=series.index)
```

**Q:** What is the purpose of the Efficiency Ratio (ER) in the calculation of KAMA?

### Key Points

- Significantly reduces whipsaws during sideways ranging markets compared to fixed-period exponential moving averages.
- Automatically tightens proximity to price action when volatility expands aggressively.

### Code Example
*Calculating VIDYA using pandas and numpy based on the Chande Momentum Oscillator volatility index.*

```python
import numpy as np
import pandas as pd

def calculate_vidya(close_prices, period=9, alpha_fast=2/3, alpha_slow=2/30):
    delta = close_prices.diff()
    gain = delta.where(delta > 0, 0.0)
    loss = -delta.where(delta < 0, 0.0)
    
    sum_gain = gain.rolling(window=period).sum()
    sum_loss = loss.rolling(window=period).sum()
    
    # Chande Momentum Oscillator as volatility index
    cmo = np.abs((sum_gain - sum_loss) / (sum_gain + sum_loss))
    
    # Dynamic smoothing constant
    sc = (2.0 / (period + 1)) * cmo
    
    vidya = np.zeros_like(close_prices)
    vidya[0] = close_prices.iloc[0]
    
    for i in range(1, len(close_prices)):
        vidya[i] = sc.iloc[i] * close_prices.iloc[i] + (1 - sc.iloc[i]) * vidya[i-1]
        
    return pd.Series(vidya, index=close_prices.index)
```

import pandas as pd

def calculate_mcginley(close, period=14, k=0.6):
    mcg = pd.Series(index=close.index, dtype=float)

### Summary
The Zero Lag MACD is an advanced momentum indicator designed to remove the inherent delay found in the standard Moving Average Convergence Divergence. By incorporating an EMA calculation that weights recent price data more heavily, it provides traders with significantly faster crossover signals during trend transitions.

### Key Points
- Eliminates traditional lag by factoring out historical delay components from standard moving averages.
- Calculates standard EMA alongside a de-lagged component to construct a much more responsive MACD line.
- Retains the core histogram and signal line structure of the original MACD, ensuring familiarity for chartists.
- Pronounced sensitivity makes it exceptional for identifying early trend entries but more susceptible to whipsaws.

### Code Example
*Demonstrates the calculation of the Zero Lag EMA component used in Zero Lag MACD.*

```python
import pandas as pd

def zero_lag_ema(series, period):
    ema1 = series.ewm(span=period, adjust=False).mean()
    ema2 = ema1.ewm(span=period, adjust=False).mean()
    return ema1 + (ema1 - ema2)
```

**❌ Common mistake:**
```python
def zero_lag_ema(series, period):
    # Mistake: directly applying a standard single EMA and calling it zero-lag

```
