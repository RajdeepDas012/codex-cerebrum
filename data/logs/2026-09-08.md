### Summary
The Vortex Indicator is a technical analysis tool composed of two oscillating lines (VI+ and VI-) that measure positive and negative trend movements. It identifies trend reversals and confirms trend direction when one line crosses over the other.

### Key Points
- Consists of two lines: VI+ (upward trend movement) and VI- (downward trend movement).
- Calculated using the distance between current highs and lows relative to previous periods.
- A bullish reversal occurs when VI+ crosses above VI- from below.
- A bearish reversal occurs when VI- crosses above VI+ from below.

### Code Example
*Calculates the Vortex Indicator lines using pandas and numpy.*

```python
import pandas as pd
import numpy as np

def vortex_indicator(df, period=14):
    tr = pd.concat([df['High'] - df['Low'], abs(df['High'] - df['Close'].shift()), abs(df['Low'] - df['Close'].shift())], axis=1).max(axis=1)
    vmp = abs(df['High'] - df['Low'].shift())
    vmm = abs(df['Low'] - df['High'].shift())
    tr_sum = tr.rolling(period).sum()
    vi_plus = vmp.rolling(period).sum() / tr_sum
    vi_minus = vmm.rolling(period).sum() / tr_sum
    return vi_plus, vi_minus
```

- Often plotted alongside a signal line to generate zero-line crossovers and divergence signals.

### Summary
The Know Sure Thing (KST) is a momentum oscillator based on the smoothed rate-of-change (ROC) values across four different timeframes. It helps traders identify major trend reversals and confirm prevailing momentum by synthesizing short, intermediate, and long-term cycles.

### Key Points
- Calculated by summing four different smoothed Rate of Change (ROC) periods, each weighted by its timeframe importance.
- Includes a signal line (typically a 9-period SMA of the KST line) to generate crossover triggers.
- Oscillates around a zero line, where positive values indicate bullish momentum and negative values indicate bearish momentum.
- Particularly useful for spotting cyclical trend turns and divergence patterns against price action.

### Code Example
*Calculating the KST indicator using pandas and custom smoothing functions*

```python
import pandas as pd

def calculate_kst(df, close_col='close'):
    roc1 = df[close_col].pct_change(10) * 100
    roc2 = df[close_col].pct_change(15) * 100
    roc3 = df[close_col].pct_change(20) * 100
    roc4 = df[close_col].pct_change(30) * 100
    
    sma1 = roc1.rolling(10).mean()
    sma2 = roc2.rolling(10).mean()
    sma3 = roc3.rolling(15).mean()
    sma4 = roc4.rolling(30).mean()
    
    kst = (sma1 * 1) + (sma2 * 2) + (sma3 * 3) + (sma4 * 4)
    signal = kst.rolling(9).mean()
    return kst, signal
```

### Summary
The Coppock Curve is a momentum-based oscillator designed primarily to identify long-term major bottom reversals in stock market indices. It is calculated as a weighted moving average of the sum of two different rates of change (ROC) periods, originally created by Edwin S. Coppock in 1962.

### Key Points
- Calculated as a 10-month weighted moving average (WMA) of the sum of a 14-month rate of change (ROC) and an 11-month ROC.
- Originally developed to spot long-term secular bull market entries on monthly charts rather than short-term trades.
- A buy signal is triggered when the Coppock Curve moves upward from below the zero line.
- Acts as a smoothed indicator designed to filter out market noise and focus on major cyclical turning points.

### Code Example
*Calculating the Coppock Curve using pandas*

```python
import pandas as pd

def coppock_curve(df, roc1=14, roc2=11, wma=10):
    roc_sum = df['Close'].pct_change(roc1) + df['Close'].pct_change(roc2)
    return roc_sum.ewm(span=wma).mean() # approximating WMA via EMA for illustration
```

### Summary
The Schaff Trend Cycle (STC) is an advanced technical indicator that combines the Moving Average Convergence Divergence (MACD) with a double-smoothed stochastic oscillator. It is designed to identify market trends faster and more reliably than traditional momentum oscillators by cycling faster through overbought and oversold levels.

### Key Points
- Calculates a traditional MACD line as a baseline momentum measure.
- Applies a first stochastic calculation to the MACD values to capture cyclical turns.
- Applies a second smoothing step using an Exponential Moving Average (EMA) to reduce false signals.
- Oscillates typically on a scale from 0 to 100, where values above 75 suggest overbought and below 25 suggest oversold conditions.

### Code Example
*Demonstrates calculating the Schaff Trend Cycle using pandas and numpy*

```python
import pandas as pd
def schaff_trend_cycle(df, short_period=23, long_period=50, cycle_length=10):
    macd = df['Close'].ewm(span=short_period).mean() - df['Close'].ewm(span=long_period).mean()
    stoch1 = (macd - macd.rolling(cycle_length).min()) / (macd.rolling(cycle_length).max() - macd.rolling(cycle_length).min()) * 100
    stoch_smooth1 = stoch1.ewm(span=cycle_length // 2).mean()
    stoch2 = (stoch_smooth1 - stoch_smooth1.rolling(cycle_length).min()) / (stoch_smooth1.rolling(cycle_length).max() - stoch_smooth1.rolling(cycle_length).min()) * 100
    return stoch2.ewm(span=cycle_length // 2).mean()
```

### Interview Questions

**A:** It combines the Moving Average Convergence Divergence (MACD) formula with a double-smoothed stochastic oscillator algorithm.  

**Q:** Why does the Schaff Trend Cycle react faster to price turns compared to a standard MACD?  
**A:** Because it applies stochastic calculations and iterative smoothing directly to the MACD line, compressing momentum shifts into a cyclical 0-100 oscillator framework that flags turns earlier.
