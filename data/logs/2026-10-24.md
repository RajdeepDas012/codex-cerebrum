bool expand_bounding_box(Node* node, const BBox& new_box) {
    BBox current, updated;
    do {
        current = node->bbox.load();
        if (current.contains(new_box)) return true;
        updated = current.merge(new_box);
    } while (!node->bbox.compare_exchange_weak(current, updated));
    return true;
}

### Interview Questions
**Q:** How do you handle concurrent node splits in a lock-free R-Tree without causing inconsistent reads for search threads?  
**A:** By using atomic pointer installations via CAS, ensuring that either the old single node or the newly split nodes are always validly reachable in the tree hierarchy during traversal.  

**Q:** Why are hazard pointers necessary when implementing a lock-free spatial index?  
**A:** Hazard pointers allow threads to safely register nodes they are currently traversing, preventing other threads from prematurely freeing or recycling those memory blocks during concurrent structural updates.
