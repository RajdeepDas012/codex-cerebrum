### Interview Questions
**Q:** How do you implement a lock-free update mechanism for a HyperLogLog register array?  
**A:** By using a compare-and-swap (CAS) loop that checks if the new computed leading-zero rank exceeds the current register value stored atomically, updating it only if the condition holds true.  

**Q:** Why is hazard pointer memory reclamation preferred over reference counting in lock-free streaming estimators?  
**A:** Hazard pointers avoid the massive atomic write overhead and cache-line bouncing associated with updating shared reference counts on every single stream insertion.
