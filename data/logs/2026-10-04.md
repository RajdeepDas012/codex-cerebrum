class PersistentNode:
    def __init__(self, val, left=None, right=None, version=0):

        self.left = left
        self.right = right
        self.version = version

def update(node, l, r, idx, val, current_version):
    new_node = PersistentNode(node.val if node else 0, node.left if node else None, node.right if node else None, current_version)
    if l == r:
        new_node.val += val
        return new_node
    mid = (l + r) // 2
    if idx <= mid:
        new_node.left = update(new_node.left, l, mid, idx, val, current_version)
    else:
        new_node.right = update(new_node.right, mid + 1, r, idx, val, current_version)
    return new_node

### Interview Questions
**Q:** How does path-copying enable persistence in a segment tree without locking?  
**A:** Path-copying creates new nodes only along the search path from the root to the modified leaf, leaving un-updated subtrees shared between versions, ensuring immutability without locking.  

**Q:** Why are hazard pointers required alongside CAS primitives in a concurrent persistent tree?  
**A:** Hazard pointers prevent other threads from freeing memory associated with older versions of nodes while a thread is actively reading or traversing them.
