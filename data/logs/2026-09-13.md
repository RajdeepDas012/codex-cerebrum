**Topic:** Spread option pricing — options on price difference of two assets  
**Category:** `probability-math`  
**Difficulty:** `advanced`  
**Language:** `python`  

### Summary
Spread options are derivative contracts whose payoff depends on the difference between the prices of two underlying assets, such as crack spreads in energy or calendar spreads in agriculture. Because the exact distribution of a difference of two log-normal prices does not have a closed-form density, valuation typically relies on analytical approximations like Margrabe's formula or Kirk's approximation.

### Key Points
- The payoff for a call spread option is $\max(S_1 - S_2 - K, 0)$ or $\max(F_1 - F_2 - K, 0)$ where $K$ is the strike price.
- Margrabe's formula provides an exact closed-form solution for the special case where the strike price $K = 0$ (effectively an option to exchange one asset for another).
- Kirk's approximation extends Margrabe's formula to handle a non-zero strike price by treating one asset plus the strike as a composite asset.
- Monte Carlo simulation is frequently required when path dependency is introduced or when multi-asset correlation structures become complex.

### Code Example
*Pricing a crack spread option using Kirk's approximation formula*

```python
import numpy as np
from scipy.stats import norm

def kirk_spread_call(F1, F2, K, T, sigma1, sigma2, rho):
    # Kirk's approximation for spread option on futures: max(F1 - F2 - K, 0)
    F2_adjusted = F2 + K
    sigma_diff = np.sqrt(sigma1**2 + (sigma2 * F2 / F2_adjusted)**2 - 2 * rho * sigma1 * sigma2 * F2 / F2_adjusted)
    d1 = (np.log(F1 / F2_adjusted) + 0.5 * sigma_diff**2 * T) / (sigma_diff * np.sqrt(T))
    d2 = d1 - sigma_diff * np.sqrt(T)
    return np.exp(-0.0 * T) * (F1 * norm.cdf(d1) - F2_adjusted * norm.cdf(d2))
```

**❌ Common mistake:**

```python
def kirk_spread_call_wrong(F1, F2, K, T, sigma1, sigma2, rho):

    d1 = (np.log(F1 - F2 - K) / np.sqrt(T)) # Fails when F1 - F2 - K < 0
    return 0.0
```

### Best Practices
- ✅ Use Margrabe's formula as a benchmark sanity check when setting the strike price to zero.
- ✅ Validate approximation outputs against a high-accuracy Monte Carlo pricing engine, especially for deep out-of-the-money or long-maturity spreads.
- ✅ Carefully calibrate the cross-asset correlation parameter $\rho$, as spread option values are highly sensitive to it.

### Interview Questions
**Q:** What is Margrabe's formula used for, and what are its key limitations?  
**A:** Margrabe's formula prices an option to exchange one asset for another (equivalent to a spread option with a zero strike). Its primary limitation is that it cannot directly handle non-zero strike prices without modifications like Kirk's approximation.  

**Q:** How does correlation between the two underlying assets affect the price of a spread call option?  
**A:** An increase in correlation typically decreases the variance of the spread (since $\text{Var}(A-B) = \sigma_A^2 + \sigma_B^2 - 2\rho\sigma_A\sigma_B$), which lowers the time value and thus reduces the price of the spread option.

**Topic:** Correlation trading — trading correlation between assets  
**Category:** `trading-strategies`  
**Difficulty:** `advanced`  
**Language:** `python`  

### Summary
Correlation trading is a quantitative strategy that profits from discrepancies between the implied correlation of multi-asset derivatives (like index options or basket swaps) and the realized correlation of their underlying components. It matters because it allows traders to express a pure view on the co-movement of assets independent of their individual directional price trends.

### Key Points
- Implied correlation is extracted from the prices of index options versus single-stock options, reflecting market expectations of future co-movement.
- Realized correlation is calculated retrospectively using historical return time series of the component assets over a specific window.
- Dispersion trading is a primary implementation of correlation trading, selling index volatility and buying single-stock volatility to profit from high constituent divergence.
- Correlation risk is highly non-linear, making position sizing and tail-risk hedging crucial due to sudden correlation spikes during market crashes.

### Code Example
*Calculates the rolling realized correlation matrix and extracts the average pairwise correlation for a basket of assets.*

```python
import numpy as np
import pandas as pd

def calculate_average_realized_correlation(returns: pd.DataFrame, window: int = 30) -> pd.Series:
    rolling_corr = returns.rolling(window=window).corr()
    n = returns.shape[1]
    # Extract upper triangle excluding diagonal to get pairwise correlations
    idx = np.triu_indices(n, k=1)
    avg_corr = rolling_corr.groupby(level=0).apply(lambda df: df.values[idx].mean())
    return avg_corr
```

```python
import numpy as np
```

### Best Practices
- ✅ Use exponential weighting or GARCH-based models to capture the time-varying nature of asset co-movements.
- ✅ Implement robust tail-risk protection, as market crashes routinely drive asset correlations toward 1.0 simultaneously.
- ✅ Monitor liquidity constraints of individual basket constituents when executing multi-leg dispersion structures.

### Interview Questions
**Q:** What is the core structural trade in a dispersion strategy?  
**A:** Selling index options (implied high correlation expectation) and buying single-stock options (implied low correlation expectation) across the index components.  

**Q:** Why do equity correlations tend to spike toward 1.0 during market downturns?  
**A:** Systemic panic, forced liquidations, and macro-driven risk-off sentiment override idiosyncratic company fundamentals, causing all stocks to sell off together.

**Category:** `trading-strategies`  
**Difficulty:** `advanced`

### Summary
Dispersion trading is a volatility arbitrage strategy that exploits the structural difference between the implied volatility of a stock index and the weighted implied volatility of its constituent stocks. It typically involves selling index options and buying constituent options to profit when constituent correlations drop and individual stock volatilities rise.

### Key Points
- Index volatility is mathematically bound to be lower than or equal to the weighted average volatility of its components plus a positive term representing average pairwise correlation.
- The core trade is short index volatility (e.g., selling straddles or variance swaps) and long component volatility (buying individual options).
- Profitability relies heavily on realized correlation dropping below implied correlation, causing constituent options to outperform index options.
- Execution requires careful beta-weighting and managing a large basket of individual stock options to match the index risk profile.

### Code Example
*Calculates the theoretical variance of an index given component weights, individual volatilities, and their correlation matrix.*

```python
import numpy as np

def calculate_index_variance(weights, vols, corr_matrix):
    cov_matrix = np.outer(vols, vols) * corr_matrix
    index_variance = np.dot(weights.T, np.dot(cov_matrix, weights))
    return index_variance
```

**❌ Common mistake:**
```python
index_vol = np.sum(weights * vols) * np.mean(corr_matrix)
```

### Best Practices
- ✅ Ensure delta-neutrality across the entire portfolio by continuously rebalancing individual stock hedges.
- ✅ Select index components that offer deep options liquidity and tight bid-ask spreads to minimize slippage.
- ✅ Monitor sector concentration to ensure the dispersion book isn't inadvertently taking a massive directional industry bet.

### Interview Questions
**Q:** Why is index implied volatility almost always lower than the weighted average implied volatility of its constituent stocks?  
**A:** Because stock prices within an index are imperfectly correlated; the diversification effect reduces the variance of the aggregate index portfolio relative to the sum of its parts.  

**Q:** What is the primary risk driver in a short-index, long-components dispersion trade?  
**A:** Correlation risk. If the average correlation among index components rises unexpectedly, the trade will lose money regardless of individual volatility changes.

### Summary
Volatility cone analysis is a visual tool used to compare current implied or historical volatility across various time horizons against historical ranges (such as min, max, and percentiles). It matters because it helps traders identify whether a particular option maturity is cheap or expensive relative to its historical behavior across different holding periods.

### Key Points
- Plots historical volatility over multiple time windows (e.g., 10-day to 250-day) on the x-axis against volatility levels on the y-axis.
- Typically displays statistical boundaries such as historical minimum, maximum, median, and 25th/75th percentiles for each timeframe.
- Helps detect term-structure anomalies where short-term volatility is mispriced relative to long-term volatility.
- Assists in structuring calendar spreads and vega-neutral option strategies by highlighting structural cheapness/richness.

### Code Example
*Calculates rolling historical volatility across multiple timeframes to build a volatility cone dataset.*

```python
import numpy as np
import pandas as pd

def calculate_vol_cone(prices, windows=[10, 30, 60, 90, 180, 250]):
    log_returns = np.log(prices / prices.shift(1))
    cone_data = {}
    for w in windows:
        rolling_vol = log_returns.rolling(window=w).std() * np.sqrt(252)
        cone_data[f'{w}d'] = {
            'min': rolling_vol.min(),
            'max': rolling_vol.max(),
            'median': rolling_vol.median()
        }
    return pd.DataFrame(cone_data)
```

### Best Practices
- ✅ Use a sufficiently long historical dataset (at least 3 to 5 years) to ensure the cone captures full market cycles.
- ✅ Overlay current implied volatility term structure points onto the historical volatility cone to spot relative value opportunities.
- ✅ Re-calculate cone boundaries periodically as market regime shifts can invalidate older baseline distributions.

### Interview Questions
**Q:** How do you construct a volatility cone, and what does it tell a trader?  
**A:** A volatility cone is built by calculating rolling historical volatility across multiple window lengths (e.g., 10d to 250d) over a long historical period, and plotting the min, max, and percentiles for each window. It tells a trader whether current option pricing is unusually high or low for specific maturities relative to historical norms.  

**Q:** If you plot current implied volatility on a historical volatility cone and see that 30-day IV is sitting at the 95th percentile, what trade idea might you consider?  
**A:** This suggests short-term options are historically expensive, making it an attractive environment for selling premium via strategies like short straddles, iron condors, or calendar spreads where you sell the rich short-term front month.
